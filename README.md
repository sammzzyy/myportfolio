# My Portfolio Website

## About the Project

This project is a personal portfolio website that I created to introduce myself, share some information about my background, and showcase projects I have worked on. I wanted to build a website where visitors could easily learn about me, see my work, and find a way to contact me.

While creating this project, I worked with Node.js, Express, EJS, HTML, CSS, and Bootstrap. I also used Git and GitHub to keep track of my progress and upload my work online.

## How I Built the Website

I started by setting up a Node.js project and using Express to create the basic structure of the website. Express helped me organize the application and manage the different pages through routes.

After setting up the project, I created separate pages for the main sections of my portfolio. These include the Home, About, Projects, and Contact pages. I used EJS as the view engine, which allowed me to create dynamic pages and reuse sections of code instead of writing everything separately for each page.

I also created shared header and footer files inside the partials folder. The header contains the navigation bar, which allows visitors to move between the different pages. The footer contains the copyright information and links to my social media profiles. Using partials made it easier to maintain a consistent layout throughout the website.

For the design, I worked with CSS to customize the appearance of the pages and used Bootstrap to help organize the layout and make the website responsive. I also included Font Awesome icons to make the navigation and other sections more visually appealing.

Finally, I tested the application locally to make sure the different pages could be accessed through their routes. Once I had the initial project structure ready, I used Git to save my changes and GitHub to upload and store the project repository.

## Pages Included

The website is divided into four main sections:

**Home Page**

This is the first page visitors see when they open the website. It serves as an introduction to my portfolio and provides access to the other sections.

**About Page**

This page gives visitors more information about me, my background, and my interests.

**Projects Page**

This section is where I showcase projects I have worked on and provide visitors with an opportunity to see some of my work.

**Contact Page**

This page provides visitors with a way to get in touch with me.

## How to Run the Project

If you would like to run the website on your own computer, follow these steps:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal inside the project folder.
4. Install the required dependencies by running:

   ```bash
   npm.cmd install
   ```

5. Start the application by running:

   ```bash
   npm.cmd start
   ```

6. Open your web browser and visit:

   ```text
   http://localhost:3000
   ```
